# إدارة الجيم

تطبيق أندرويد بيشتغل بدون نت: اشتراكات (شهر / نص شهر)، حصص، أرباح يومية، إشعارات لما الاشتراك ينتهي، ورقم سري لفتح التطبيق.

## أسهل طريقة لعمل الـ APK (من غير ما تنزل أي برنامج)

1. اعمل مستودع جديد على GitHub وارفع كل ملفات المجلد ده فيه (مع مجلد `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد ما يخلص (حوالي 5-8 دقايق) افتح التشغيل ونزّل **gym-manager-apk** من آخر الصفحة.
4. فك الضغط وانقل `app-debug.apk` للتليفون وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## بالطريقة العادية (على الكمبيوتر)

محتاج Node 20+ و Android Studio.

```bash
npm install
npx cap add android
npm run icons
bash scripts/patch-android.sh
npx cap sync android
npx cap open android      # ومن Android Studio: Build ← Build APK
```

## الأمان

- **قاعدة البيانات**: SQLite مشفرة بـ SQLCipher. مفتاح التشفير بيتعمل عشوائي أول مرة ويتخزن في Android Keystore، فملف القاعدة لوحده مالوش لازمة لو اتسحب من التليفون.
- **الرقم السري**: 6 أرقام، بيتخزن مجزّأ (PBKDF2) مش بالنص. بعد 5 محاولات غلط بيتقفل مدة بتزيد.
- **قفل تلقائي**: التطبيق بيتقفل لو خرجت منه أكتر من 30 ثانية، وبيتخفى من شاشة التطبيقات الأخيرة.
- **النسخ الاحتياطي التلقائي**: متقفل (`allowBackup=false`).
- **النسخة اليدوية**: بتتشفر بكلمة سر (AES-256-GCM).

مفيش نظام "مستحيل يتخترق". الحماية دي بتمنع الوصول للبيانات من برة التطبيق ومن حد ماسك التليفون. لكن لو حد عرف الرقم السري والتليفون مفتوح قدامه، هيشوف البيانات. الرقم السري مفيش طريقة لاسترجاعه لو نسيته (الحل الوحيد مسح بيانات التطبيق، وده بيمسح كل حاجة)، فخد نسخة احتياطية بشكل دوري.

## الإشعارات

- بتتجدول على التليفون نفسه، فبتشتغل والتطبيق مقفول ومن غير نت، وبتفضل بعد إعادة تشغيل التليفون.
- وقت التنبيه يتغير من **الإعدادات**، وفيه تنبيه قبل الانتهاء بيوم.
- على بعض التليفونات (شاومي، أوبو، ريلمي، سامسونج) لازم تقفل تحسين البطارية للتطبيق وتفعّل التشغيل التلقائي، وإلا النظام ممكن يأخر الإشعار.
- أندرويد 13 وأحدث بيطلب إذن الإشعارات، وأندرويد 12 وأحدث ممكن يطلب إذن "المنبهات والتذكيرات" (بيفتح لك شاشة الإعدادات تلقائي).

## ملاحظات

- ده APK تجريبي (debug) للتثبيت المباشر. لو هتنزله على Google Play محتاج توقيع release.
- لو فتحت `www/index.html` في المتصفح بيشتغل للتجربة بس (من غير تشفير ولا إشعارات).
